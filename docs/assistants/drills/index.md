status: active

Verification checklists. A drill is what you run to prove you did not break
something, especially something that has broken before.

```text
# Drill - <Name>

## Use when
## Checklist
[ ] step
[ ] step
```

Every entry in a domain's `failures.md` is a candidate drill.
