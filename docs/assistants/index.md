status: active

## Purpose

Packets are small routing, procedure, pattern, and verification files used by any
assistant. They supplement canonical docs; they do not replace them.

## Folders

```text
agents/     role-specific guidance ("you are doing X work; read these, obey these")
skills/     repeatable procedures and checklists
patterns/   reusable design patterns this project has settled on
drills/     verification checklists
handoffs/   task handoff packets (see docs/worklogs/assignments.md)
```

## Rules

- Do not put long project history here. History goes in worklogs.
- Do not put full design docs here. Those live with their domain.
- A packet that is only read once was probably a worklog entry.
