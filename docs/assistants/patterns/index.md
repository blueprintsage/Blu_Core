Design patterns this project has actually settled on - named, so an assistant
reuses the existing answer instead of inventing a fourth one.

A pattern earns a file once it appears in two or more places. Before that it is
just code.

```text
# <Name> Pattern

## Problem
## Solution
## Where it is used
## When NOT to use it
```
